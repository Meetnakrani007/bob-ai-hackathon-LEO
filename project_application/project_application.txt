3. PROJECT / APPLICATION

SupplyGuard AI is organized into operational workspaces, each covering one part of the disruption-response workflow:

--------------------------------------------------------------------------------
WORKSPACE DIRECTORY
--------------------------------------------------------------------------------
1. Mission Control:
   Executive dashboard — active disruptions, total cargo exposure, shipments monitored, cold-chain status

2. Threat Intel & Ports:
   Verifies whether a reported disruption is real, with a confidence score and evidence sources

3. Cold-Chain Guard:
   Live temperature telemetry for refrigerated cargo; triggers emergency truck intercept before spoilage

4. Scenario Matrix:
   Side-by-side comparison of alternative response plans (cost, transit time, risk)

5. Tactical Maritime Map:
   Visual map of ports, vessels, and routes

6. Fleet & Cargo Manifest:
   Full shipment/fleet list with per-item risk scores and one-click mitigation

7. 72h Cascade Simulator:
   Projects the financial cost of not acting over the next 72 hours

8. Governance & Audit Trail:
   Immutable log of every approved action, actor, and justification

9. AI Operations Copilot:
   Natural-language chat interface that calls the MCP tools automatically to answer operator questions

10. Operations & RBAC Guide:
    In-app reference for role permissions

11. Admin Personnel Console:
    User/role management

--------------------------------------------------------------------------------
TECHNOLOGY STACK
--------------------------------------------------------------------------------
- Frontend: React 18, TypeScript, Vite, TailwindCSS (Port 5173)
- Backend: Node.js, Express, TypeScript (Port 5001)
- MCP Server: @modelcontextprotocol/sdk, 10 supply-chain tools (Port 5001 / Stdio)
- Analytics Engine: Python 3, FastAPI, NumPy, Pandas (Port 8000)
- Database: MongoDB / SQLite fallback (Port 27017)
- Mapping & GIS: Leaflet, OpenStreetMap, 28 Indian ports

--------------------------------------------------------------------------------
QUICK START INSTRUCTIONS
--------------------------------------------------------------------------------
1. Python Analytics:
   cd src/python
   python3 -m venv .venv && source .venv/bin/activate
   pip install -r requirements.txt
   uvicorn app.main:app --host 0.0.0.0 --port 8000 --reload

2. Node.js Backend & MCP:
   cd src/backend
   npm install && npm run dev

3. React Frontend:
   cd src/frontend
   npm install && npm run dev -- --port 5173

Docker One-Command Launch:
   docker-compose up --build
